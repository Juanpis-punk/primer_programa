# HolaMundo

Aplicación sencilla desarrollada en Java que solicita el nombre del usuario mediante la consola y posteriormente muestra un mensaje de bienvenida utilizando una ventana emergente con JOptionPane.

## Características

- Solicita el nombre del usuario desde la consola.
- Utiliza la clase Scanner para leer datos.
- Muestra mensajes mediante JOptionPane.
- Ejemplo básico del uso de entrada por consola e interfaz gráfica en Java.

##  Ejemplo de ejecución

(Poner captura xfa)

### Consola

```text
¿Cuál es tu nombre?:
```

### Ventanas emergentes

```text
Hola mundo.
```
```text
Bienvenido: (nombre)
```

## Código principal

El programa realiza las siguientes acciones:

1. Crea un objeto `Scanner`.
2. Solicita el nombre del usuario.
3. Guarda el nombre ingresado.
4. Muestra mensajes utilizando `JOptionPane`.

---

## Ejemplo de uso

1. Ejecuta el programa.
2. Escribe tu nombre en la consola.
3. Presiona **Enter**.
4. Aparecerán ventanas con los mensajes:

```text
Hola mundo.
```
```text
Bienvenido: (nombre)
```
